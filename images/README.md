# Images Folder

Store project images here. Upload your project screenshots and reference them in the portfolio.

## Image Naming Convention:
- `buzz-brew-hero.jpg` - Buzz & Brew hero/main image
- `evergreen-legacy-hero.jpg` - EverGreen Legacy hero/main image
- `[project-name]-screenshot-[number].jpg` - Additional screenshots

## How to Upload:
1. Go to: https://github.com/gregramos04/gregramos04.github.io/tree/main/images
2. Click "Add file" → "Upload files"
3. Drag and drop your images
4. Commit the changes

The portfolio will automatically display images from this folder once uploaded.
